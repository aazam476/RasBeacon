# Milestone 5: hardware test plan (hotel login pages)

**Goal:** confirm that on a network with a login page (a "captive portal"),
with the VPN's kill switch on, your phone shows RasBeacon's notice by
itself, login mode lets you log in, and the VPN comes up afterwards with
nothing left open.

## What you need

- RasBeacon with the latest image, the VPN set up and working (see the
  [milestone 4 plan](m4.md)), **kill switch on**.
- A network with a login page: a hotel, café, airport, library or campus
  guest network. (Many phones can't create one, so this needs a real one.)
  Add it on the **Internet** page (usually it's open, no password).
- An iPhone and/or an Android phone on RasBeacon's hotspot.

Copy the **report template** at the end and fill it in.

## 1. The notice opens by itself

1. With RasBeacon on the network with the login page, wait up to 2
   minutes after the Status page shows the Wi-Fi uplink connected.
2. The Status page should show *This network shows a login page.*
3. On the phone (on RasBeacon's hotspot), turn Wi-Fi off and on, or just
   wait.
4. **Report:**
   - iPhone: did a "Log in" sheet open by itself showing *This network
     needs a login*? (If not, open Safari and go to `http://10.87.0.1/#portal`.)
   - Android: did a "Sign in to network" notification appear, and did it
     open the same page?

## 2. Log in with login mode

1. In the sheet (or page), tap **Start login mode**.
2. After about 2 seconds the page should go to the network's login page.
   If not, tap **Open the login page**.
3. Log in or accept the terms.
4. **Report:**
   - did the network's login page load?
   - after logging in, how long until RasBeacon's Status page says the VPN
     is *Connected* and login mode is off?
   - on the phone, does a "what is my IP" site show your VPN server's
     address afterwards?

## 3. Nothing stays open

1. After step 2, with the VPN connected, open a long download or video on
   the phone, then on RasBeacon's Status page check the VPN is connected.
2. **Report:** does everything keep working through the VPN (IP check
   shows the VPN server)?

## 4. Time limit (optional, if the network lets you)

1. Forget the login (some networks offer "log out"; otherwise skip this),
   so the login page appears again.
2. Start login mode but don't log in.
3. **Report:** after 10 minutes, does login mode end by itself (the notice
   shows *Start login mode* again)? Does **10 more minutes** work, and does
   it stop at 30 minutes in total?
