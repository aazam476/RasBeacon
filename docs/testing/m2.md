# Milestone 2: hardware test plan

**Goal:** confirm that devices on RasBeacon's hotspot reach the internet
through an Ethernet cable or an upstream Wi-Fi network, that the Ethernet
port's client-port mode is safe, and measure how the hotspot and the Wi-Fi
uplink share the 2.4 GHz band.

If you haven't finished the [milestone 1 checks](m1.md) with the Archer T3U
yet (the 10-device gate and power), please do those with this image too:
everything from milestone 1 still applies.

## What you need

- **The board and adapter:** your Raspberry Pi 4 and Archer T3U.
- **The image:** from the latest "Release images" run on GitHub (Actions tab
  → Release images → the newest run → *Artifacts*).
- **An upstream network:** your home router, with an Ethernet cable to it.
  Its Wi-Fi name and password. If it has separate 2.4 GHz and 5 GHz
  networks, note both.
- **A phone** and **a laptop** (with `iperf3` for step 8; macOS:
  `brew install iperf3`). A second computer on your home network for
  step 8.

There is no in-place update yet (that's milestone 6), so flashing the new
image means doing setup again.

Copy the **report template** at the end, fill it in as you go, and paste it
back.

## 1. Flash and set up

1. Flash the image (Imager: *Use custom*, **No** to OS customisation).
2. Plug in the Archer T3U. **Don't** plug in Ethernet yet. Power on.
3. Finish setup from your phone as before, join your hotspot, and log in at
   `http://10.87.0.1`.
4. **Report:** the Status page's **Internet** section. We expect
   "Not connected" and Wi-Fi "No networks saved".

## 2. Ethernet uplink

1. Plug an Ethernet cable from your home router into the Pi.
2. Within about 10 seconds, the Status page (it refreshes itself) should
   show **Connected by Ethernet** and an address from your home network.
3. On the phone (still on RasBeacon's hotspot), open a few websites.
4. **Report:**
   - does the Status page show "Connected by Ethernet", and which address?
   - do websites load on the phone?
   - does the phone show any "No internet connection" warning?

## 3. Wi-Fi uplink

1. Go to the **Internet** page and tap **Look for nearby networks**.
2. Tap your home network, type its password into **Network password**, tap
   **Add to list**, then **Save**.
3. Unplug the Ethernet cable.
4. Within about 20 seconds, the Status page should show
   **Connected to Wi-Fi "your network"** with the signal and band.
5. On the phone, reload a website (open connections may need a moment to
   recover after the switch).
6. Plug the Ethernet cable back in: the Status page should switch back to
   Ethernet.
7. **Report:**
   - did the scan list your network? Anything odd in the list (missing
     networks, strange names)?
   - how long did the switch to Wi-Fi take?
   - signal and band shown
   - did websites load over Wi-Fi?
   - did it switch back to Ethernet?

## 4. Network security types

1. **WPA3:** go to **System → Download diagnostics**, open the file and
   find the line starting with `key_mgmt=` (in the `wpa_cli ... status`
   section). **Report:** its value (`WPA2-PSK`, `SAE` = WPA3, or
   `FT-PSK`...).
2. **Open network (optional):** on a second phone, turn on its personal
   hotspot. iPhones always use a password, so use it as a password network,
   or use an Android hotspot set to "None". Add it on the Internet page,
   move it **Up** to the top, and save. With Ethernet unplugged and your home
   network out of range (or removed from the list), check that RasBeacon
   joins it. **Report:** works yes/no.
3. **Priority (optional):** with both your home network and the phone
   hotspot saved and in range, the one at the top of the list should be
   used. Use **Up/Down** and **Save** to swap them. **Report:** does
   RasBeacon follow the order? (It may take up to a minute to move to the
   preferred network.)

## 5. DNS and IPv6

1. On the laptop (on the hotspot), run `nslookup example.com 8.8.8.8`.
   RasBeacon redirects every DNS question to itself, so this should answer
   even though 8.8.8.8 isn't asked directly. **Report:** answered yes/no.
2. On the phone, open [test-ipv6.com](https://test-ipv6.com).
   **Report:** the score and the summary line.
   - If your home network has IPv6, the Status page should say
     "IPv6 for your devices: Yes" and the test should find IPv6.
   - If not, it should say "No (IPv4 only)", and the test page must still
     load quickly (no long waits).

## 6. Ethernet client port

1. On the **Internet** page, choose **Client port** for the Ethernet port
   and **Save**. Keep the Wi-Fi uplink connected (step 3).
2. Plug the laptop into the Pi's Ethernet port with a cable (and turn the
   laptop's Wi-Fi off).
3. **Report:**
   - does the laptop get a `10.87.0.x` address?
   - does it have internet (through RasBeacon's Wi-Fi uplink)?
   - can it reach the phone on the hotspot (for example `ping` the phone's
     address from the Status page)?
4. **The safety check:** unplug the laptop and plug the Pi's Ethernet port
   into your **home router** instead (still set to *Client port*).
5. **Report:**
   - the Status page should show a warning that the port "seems to be
     plugged into a network". Does it?
   - check that other computers on your home network still get their normal
     addresses (for example, turn a phone's home Wi-Fi off and on again).
6. Set the Ethernet port back to **Uplink** and save.

## 7. Settings survive power cuts

1. With your home Wi-Fi saved and Ethernet unplugged, pull the power, wait
   5 seconds, and plug it back in.
2. **Report:** after about a minute, does the Status page show the Wi-Fi
   uplink connected again, without re-entering anything?

## 8. Speed, and the 2.4 GHz question

Both radios sit centimetres apart. When the hotspot and the uplink both use
2.4 GHz, they may slow each other down. These measurements decide
RasBeacon's default.

On the second computer (on your **home** network), run `iperf3 -s`. Note its
address. From the laptop on RasBeacon's hotspot, run each test below as
`iperf3 -c <address> -t 20` and then with `-R` added, and note the two
`receiver` lines. The laptop stays about 2 m from the Pi.

| Test | Hotspot | Uplink |
|---|---|---|
| A | 2.4 GHz (default) | Ethernet |
| B | 2.4 GHz | Wi-Fi on **2.4 GHz** |
| C | 2.4 GHz | Wi-Fi on **5 GHz** (if your router has a 5 GHz network) |
| D | 5 GHz (Hotspot page) | Wi-Fi on 2.4 GHz |

The Status page shows the uplink's band. To pick one band, save only that
network (2.4 GHz or 5 GHz) on the Internet page. For test B, also note the
uplink's channel from the diagnostics file (`freq=` in the `wpa_cli` section:
2412 = channel 1, 2437 = 6, 2462 = 11) and the hotspot's channel from the
Status page.
